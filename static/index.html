本地大模型聊天

支持对话、图片理解、文档解析与联网检索，推理全部在本机 llama.cpp 上完成。

  • 左侧列表可以随时回到以前的对话，也能重命名、搜索和删除
  • 把图片拖进窗口、粘贴或直接点击附件按钮上传
  • 点击文档按钮上传 MD / PDF / DOCX / TXT / XLSX / PPTX，解析后可结合提问分析
  • Enter 发送，Shift+Enter 换行
  • 开启「联网检索」后，模型会在需要时自行查证并附来源

设置

带输入框的项保存后立即对下一条消息生效，并写入 runtime/settings_override.json（优先级高于 .env）。 其余项只读，下面注明了修改方式。

发消息

Enter 发送，Shift+Enter 换行。回答以流式方式逐字出现，期间「发送」会变成「停止」，随时可以打断。

图片理解

把图片拖进窗口、Ctrl+V 粘贴，或点击输入框左侧的附件按钮上传。单条消息最多 4 张， 单张不超过 12MB，支持 png / jpeg / webp / gif。 只有带 mmproj 投影文件的视觉模型才能看图；换成纯文本模型后顶栏的附件按钮会自动灰掉， 已上传的图片也会在本次请求中被剥掉，不会报错。

文件解析

点击输入框左侧的文档按钮，或把文件拖进窗口，即可上传 .md .txt .pdf .docx .xlsx .pptx；单条消息最多 3 个，单个不超过 25MB。 解析在服务端完成，提取出的正文以可折叠卡片显示，展开可以核对内容。 发送时正文会和你的问题一起进入上下文，之后每一轮追问都仍然带着，所以能连续追问同一份文件。

几点限制：2007 以前的 .doc / .xls / .ppt 无法解析，请在 Office 或 WPS 里「另存为」新格式后再上传； 扫描版 PDF 只有图片没有文字层，本应用不做 OCR，会明确提示，此时可以改用图片上传（视觉模型支持看图）； 当历史加文档超过模型上下文预算时，会自动省略最旧那几轮的文档正文并在状态行说明，最新一份永远保留，不会报错。 首次解析 PDF 需要加载布局分析模型，会慢几秒。

联网检索

勾选顶栏「联网检索」后，模型会自行判断是否需要查证，而不是每条消息都搜。 检索以工具调用的形式进行，因此只有模板支持工具调用的模型可用；不支持时该开关会自动灰掉并取消勾选。 回答正文里会出现 [1] 这样的来源编号，下方列出对应的标题与链接。 使用哪个检索源见「设置」中的 search_provider。

深度思考

勾选后模型会先输出一段推理过程再作答，适合数学、代码、多步分析，但明显更慢， 而且推理和答案共用同一份 token 预算。日常问答不需要开。

历史对话

左侧列表是全部对话，点击即可回到并继续。可以重命名、删除，也可以按标题或正文内容搜索。 对话存在服务端的 runtime/history/ 里，每个会话一个 JSON 文件， 连同上传过的图片一起保留；删除整个目录即清空全部历史。 顶栏的复制按钮可以把当前整段对话复制成文本，每条消息右上角的图标则复制单条。
